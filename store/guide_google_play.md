# Google Play 封閉測試：照順序做（用電腦瀏覽器）

依據：Google Play Console 說明中心（2026/11/27 查）。規定：個人帳號要「至少 12 位測試者、連續加入 14 天」才能申請正式上架。

## 事前準備
- [ ] `gto-v11.aab`（桌機 `app_build\output\` 裡，雙擊 build_app.bat 產生）
- [ ] 12 位以上測試者的 Gmail（必須是他們 Android 手機登入 Google Play 的那個帳號）
- [ ] 隱私權政策的公開網址
- [ ] 公開聯絡信箱
- [ ] 圖：App 圖示 512×512、主題圖片 1024×500、手機截圖至少 2 張

## A. 建立應用程式
1. play.google.com/console → 所有應用程式 → **建立應用程式**
2. 名稱：`GTO 德撲研究所`；預設語言：中文（繁體）
3. 應用程式或遊戲：**應用程式**；免費或付費：**免費**（完整版用 App 內購買）
4. 勾選兩項聲明 → 建立

## B. 資訊主頁上的「設定應用程式」（一項一項做）
| 項目 | 怎麼填 |
|---|---|
| 隱私權政策 | 貼上網址 |
| 應用程式存取權 | 「所有功能都不需要特殊存取權」（不用登入） |
| 廣告 | 「否，我的應用程式不含廣告」 |
| 內容分級 | 填問卷：類別選「參考、新聞或教育」；暴力、性、粗話、毒品都選否；**賭博相關：有「模擬賭博」主題（撲克教學），不涉及真錢、不能贏得真實獎金** |
| 目標對象 | 只選 **18 歲以上** |
| 資料安全性 | 「不會收集或分享任何必要的使用者資料類型」；資料是否加密、可否要求刪除等照畫面選「不適用／未收集」 |
| 政府應用程式 | 否 |
| 金融功能 | 「我的應用程式不提供任何金融功能」 |
| 健康 | 無健康功能 |
| 應用程式類別與聯絡資訊 | 類別：**教育**；填聯絡信箱 `reed880109@gmail.com` |
| 商店資訊 | 名稱、簡短說明、完整說明（見 listing_zh-TW.md）；上傳圖示、主題圖片、截圖 |

## C. 建立封閉測試
1. 左側選單 **測試及發布 → 測試 → 封閉測試**
2. 用預設的 Alpha 軌道按 **管理測試群組**（或「建立測試群組」）
3. **國家/地區** 分頁 → 新增 **台灣**
4. **測試人員** 分頁 → 建立電子郵件清單 → 貼上 12 位以上的 Gmail → 儲存；「意見回饋網址或電子郵件」填 `reed880109@gmail.com`
5. **版本** 分頁 → **建立新版本** → 上傳 `gto-v11.aab`
   - 第一次會問 Play 應用程式簽署：選 **由 Google 管理**（預設）
   - 版本資訊（zh-TW）：`第一個測試版。歡迎回報任何問題。`
6. 下一步 → 儲存 → **送審**（第一次審查通常幾天內）

## D. 審查通過後
1. 封閉測試頁面 → 測試人員分頁 → 複製 **「透過網頁加入」的連結**
2. 傳給 12 位測試者，請他們：(1) 點連結按「成為測試人員」 (2) 從 Google Play 安裝 (3) **14 天內不要退出、不要移除**，並且真的打開來用
3. 14 天計時從第 12 位加入那天起算

## E. App 內購買（完整版）
1. 左側 **透過 Play 營利 → 產品 → 應用程式內產品**（要先上傳過一個含付款功能的版本才會開放）
2. 建立產品，**產品 ID 一定要是 `pro_unlock`**（程式裡寫死的）
3. 名稱：完整版；設定價格 → 啟用
4. 設定 → 授權測試：把測試者的 Gmail 加進「授權測試人員」，他們購買不會真的扣款

## F. 14 天後
資訊主頁 → **申請正式版發布權** → 回答測試過程的問題（收到什麼回饋、改了什麼）。
